# AddonCove v1.0.0 — First public release

A free, GPL-licensed N-panel manager for your Blender add-ons.

**Includes:** installed add-on list, categories, custom names, per-item and bulk enable/disable, ZIP/PY installer, confirmed uninstall for supported user add-ons, tab management, backup import/export, normal Blender theme and N-Panel Only default ON.

**Install:** Download `addoncove_v1.0.0_blender_install.zip`, then use **Edit → Preferences → Get Extensions → Install from Disk** in Blender 5.2+.

**Migration:** This was previously developed as Add-on Organizer v1.2.2. Disable the older add-on before switching and restart Blender. Earlier metadata may be copied automatically; export/import your old JSON as a backup.

**Release maturity:** Initial community/testing release. Static checks and restricted registration simulations were run; thorough real-Blender tests are outstanding. Back up settings before managing or removing add-ons.
