# Contributing

Thanks for helping improve AddonCove.

- Open an issue with a reproducible case before larger feature changes.
- Test changes using a separate Blender settings directory or a backup.
- Specify Blender version, operating system and third-party add-ons needed to reproduce the behavior.
- Do not add code that deletes files without an explicit and clearly confirmed user action.
- Follow the project's GPL-3.0-or-later license and disclose the origin and license of any third-party code you add.
- No guarantee is made that every user-installed add-on is compatible with management operations.
