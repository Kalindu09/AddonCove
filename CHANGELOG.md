# Changelog

## v1.0.0 — First public release

- Introduced the **AddonCove** name, manifest identifier, N-panel UI tab and internal namespace.
- Based on the previous **Add-on Organizer v1.2.2** development code, retaining its features and deferred registration fix.
- Adds best-effort read-only migration of earlier category and custom-name JSON data.
- Add-on listing, categorization, rename, install, enable/disable, uninstall, refresh and N-panel management.
- Defaults N-Panel Only to ON; follows Blender's native theme colors.
- Prepared GPL source and first public GitHub release package.

Note: Previous v1.2.x versions were unpublished development builds; v1.0.0 is the first public release numbering, not a feature rollback.
